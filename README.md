# Litovle.cz

**Nezávislý občanský projekt pro Litovel a její místní části.**

Zpřístupňujeme veřejná data, vytváříme užitečné nástroje a podporujeme otevřenost a transparentnost místní samosprávy.

Naším cílem je, aby informace o dění ve městě a rozhodování jeho samosprávy byly snadno dostupné, srozumitelné a ověřitelné.

## Naše projekty

- **[Litovle.cz](https://litovle.cz)** – hlavní web projektu, informace o městě a občanské iniciativy.
- **[Svoz odpadu](https://svoz.litovle.cz)** – přehled termínů svozu odpadu podle ulic a místních částí.
- **Usnesení města** – automatizované získávání a zpracování usnesení rady a zastupitelstva města.

## Naše zásady

- **Transparentnost** – veřejné informace mají být dostupné všem.
- **Ověřitelnost** – vycházíme z dohledatelných zdrojů a odkazujeme na původní dokumenty.
- **Nezávislost** – nejsme spojeni s vedením města ani žádnou politickou stranou.
- **Otevřenost** – zdrojové kódy našich nástrojů zveřejňujeme na GitHubu.
- **Odpovědnost** – usilujeme o věcnou komunikaci a opravujeme zjištěné chyby.
